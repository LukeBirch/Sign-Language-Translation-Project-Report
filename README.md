# Sign Language Translation — Advanced Project

This repository contains my **Advanced Project report** on **Sign Language Translation**, completed as part of my MEng Computer Science degree at Durham University.

## Project

**Title:**
*How Does Using Improved Pseudo-Glosses Impact the Performance of a Gloss-Free Sign Language Translation Model?*

The project investigates the use of **pseudo-gloss generation** to improve gloss-free Sign Language Translation (SLT).

## Report

📄 **[Read the Full Project Report](Advanced_Project_Report.pdf)**

The report covers:

* Gloss-free Sign Language Translation
* British Sign Language (BSL)
* The BOBSL dataset
* Pseudo-gloss generation
* Transformer-based SLT models
* Model architecture and training
* BLEU, ROUGE and CHRF evaluation
* Experimental results and analysis
